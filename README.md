# ЛР1–3

**Дисциплина:** Цифровая электроника и микропроцессорные устройства в медицинской технике  
**МК:** STM32F303RE (ARM Cortex-M4, 72 МГц)  
**IDE:** Atollic TrueSTUDIO 9.3  

Прошивка PWM-контроллера с управлением по UART, объединяющая функционал трёх лабораторных работ.

---

## Лабораторные работы

### ЛР1 — Таймеры. ШИМ-контроллер
- Таймеры TIM1 и TIM3 настроены в режиме PWM1 (счёт вверх)
- 8 каналов ШИМ на светодиоды LD0–LD7
- Мерцание с частотой 10 Гц (ШИМ 50%)
- Sweep заполнения 0→100→0% с шагом 5% каждые 100 мс
- Boot scan — визуальная проверка всех светодиодов при запуске
- **Автозапуск демонстрации sweep duty** (включён по умолчанию)
- **Кнопка PC13 (USER)** — переключает автодемо: нажатие останавливает sweep и гасит все каналы, повторное нажатие — перезапускает
- При остановленном автодемо можно корректно тестировать команды установки частоты и заполнения через UART

### ЛР2 — UART, прерывания, управление каналами
- USART3, PC10 (TX) / PC11 (RX), 9600 бод, 8N1
- Приём и отправка по прерываниям через ring buffer
- 8-байтный протокол обмена с XOR-контрольной суммой
- Команды: установка частоты (0x01), заполнения (0x02), вкл/выкл (0x03)
- Запросы: частота (0x81), заполнение (0x82), состояние (0x83)
- Ping (0x00), sweep (0x04/0x05), инверсия (0x06), snapshot (0x84–0x87)

### ЛР3 — Циклический буфер, DMA, кнопка
- Ring buffer 256 байт (RX и TX) — оптимизированный (степень двойки)
- Альтернативная реализация `ring_buffer.c` (`buffer_init`, `buffer_addToEnd`, `buffer_getFromFront`)
- DMA TX: паттерн Вариант 1 (0..127, 128..64, 65..255) по команде 0xAC
- DMA RX: приём конфигурации CONFIG_PUSH по команде 0x09
- Изменение скорости UART командой 0xAD
- Кнопка PC12 (BTN2) с антидребезгом TIM6 (30 мс)
- Последовательность действий по команде 0x7B

## Аппаратная конфигурация

| Параметр | Значение |
|---|---|
| Тактирование | HSI 8 МГц → PLL ×9 = 72 МГц SYSCLK |
| UART | USART3, PC10 (TX) / PC11 (RX), 9600 бод, 8N1 |
| ШИМ | TIM3 (CH1–4: PC6, PC9, PC7, PC8) — каналы 1–4 |
| | TIM1 (CH1–4: PA9, PA8, PA11, PA10) — каналы 5–8 |
| DMA | DMA1_CH2 (USART3_TX), DMA1_CH3 (USART3_RX) |
| Кнопка (ЛР6) | PC12 (EXTI12, falling edge, pull-up, антидребезг TIM6) |
| USER (ЛР4) | PC13 (EXTI13, falling edge, без подтяжки — переключение автодемо) |

## Таблица команд протокола

| Код | Имя | Описание |
|---|---|---|
| 0x00 | CMD_PING | Ping (эхо) |
| 0x01 | CMD_SET_FREQ | Установка частоты канала |
| 0x02 | CMD_SET_DUTY | Установка заполнения канала |
| 0x03 | CMD_SET_STATE | Включение/выключение каналов |
| 0x04 | CMD_SWEEP_SET | Настройка sweep |
| 0x05 | CMD_SWEEP_CTRL | Управление sweep (старт/стоп) |
| 0x06 | CMD_SET_INVERT | Инверсия фазы ШИМ |
| 0x09 | CMD_CONFIG_PUSH | Приём конфигурации через DMA |
| 0x0C | CMD_DMA_MARK | Маркер начала/конца DMA |
| 0x7B | CMD_BTN_SET | Настройка последовательности кнопки |
| 0x81 | CMD_GET_FREQ | Запрос частоты |
| 0x82 | CMD_GET_DUTY | Запрос заполнения |
| 0x83 | CMD_GET_STATE | Запрос состояния |
| 0x84–0x87 | CMD_SNAP_* | Snapshot группы каналов |
| 0xAB | CMD_DMA_OFF | Выключить DMA |
| 0xAC | CMD_DMA_ON | Включить DMA (паттерн Вариант 1) |
| 0xAD | CMD_SET_BAUD | Изменение скорости UART |

## Формат кадра

```
[0x7C][cmd][data0][data1][data2][data3][data4][xor]
```

`xor = cmd ⊕ data0 ⊕ data1 ⊕ data2 ⊕ data3 ⊕ data4`

## Управление автодемо ЛР1

При включении питания автоматически запускается демонстрация sweep duty на всех 8 каналах (freq=1000 Гц, step=5%, period=100 мс).

**Кнопка PC13 (USER)** переключает состояние:
- **Нажатие 1** — sweep останавливается, все каналы выключаются
- **Нажатие 2** — sweep перезапускается на всех каналах

> **Примечание:** Пока автодемо активно, команды `SET_FREQ` и `SET_DUTY` могут не давать видимого эффекта — sweep перезаписывает duty каждые 100 мс. Сначала остановите автодемо кнопкой PC13, затем отправляйте команды.

Для полного отключения автодемо — закомментируйте вызов `lab4_start()` в функции `main()`.
